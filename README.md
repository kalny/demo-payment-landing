# Vue3 + Paddle Demo

> 🚧 **Work in Progress** — this project is currently under active development.

This is the frontend part of the [Laravel + Paddle Demo](https://github.com/kalny/demo-payment-api).

## Installation

```bash
git clone https://github.com/kalny/demo-payment-landing.git

cd demo-payment-landing

cp .env.example .env

# set up environment variables
nano .env

npm install

npm run dev
```
